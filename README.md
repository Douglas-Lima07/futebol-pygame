# ⚽ Futebol Pygame

Jogo de futebol 2D desenvolvido em Python utilizando Pygame.

## Tecnologias

- Python
- Pygame

## Funcionalidades

- Movimentação dos jogadores
- Controle da bola
- Colisões
- Sistema de pontuação
- Tela de vitória
- Eventos de teclado

## Conceitos praticados

- Programação Orientada a Objetos
- Game Loop
- Eventos
- Colisões
- Gerenciamento de estados
- Organização modular
